# Global Workforce Layoff Intelligence Dashboard

## Project Overview

This project analyzes global layoff trends across industries, countries, and company growth stages. The objective was to transform raw layoff data into actionable insights through SQL-based data cleaning and an interactive Power BI dashboard.

## Key Insights

* Retail, Consumer, and Food industries experienced the highest layoffs.
* Post-IPO companies recorded the largest workforce reductions.
* The United States accounted for the highest number of layoffs.
* Workforce reductions averaged approximately 20% across affected companies.

## Dashboard Features

* Industry Analysis
* Country Analysis
* Company Stage Analysis
* Layoff Trends Over Time
* Interactive Filters and Drill-through Analysis

## Strategic Recommendations

* Implement early-warning layoff risk indicators.
* Align hiring decisions with verified revenue growth.
* Adopt flexible workforce planning models.
* Apply stage-based hiring governance.
* Develop industry-specific workforce risk strategies.
